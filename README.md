# 🪔 Diwali Sales Analysis

## 📌 Project Overview

**Diwali Sales Analysis** is a Python-based data analysis project focused on exploring sales data to understand customer purchasing behavior, product preferences, and sales trends during the Diwali festival.

The project uses data analysis and visualization techniques to transform raw sales data into meaningful insights that can help businesses understand their customers and make better business decisions.

## 🎯 Objectives

- Analyze customer purchasing patterns during Diwali.
- Identify customer segments and product categories.
- Explore sales trends using data analysis.
- Understand customer demographics and purchasing behavior.
- Create visualizations to communicate insights effectively.
- Support data-driven business decisions.

## 🛠️ Technologies Used

- **Python** — Programming language
- **Pandas** — Data cleaning and manipulation
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Jupyter Notebook** — Data analysis and experimentation

## 📊 Project Workflow

1. **Data Collection:** Load the sales dataset.
2. **Data Cleaning:** Handle missing values, incorrect data types, and duplicate records where applicable.
3. **Exploratory Data Analysis (EDA):** Explore customer details, product categories, and sales patterns.
4. **Data Visualization:** Create charts and graphs to understand the data.
5. **Insights:** Interpret the results and identify useful business patterns.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Athrav5/diwali_sales_analysis.git
```

### 2. Navigate to the Project Folder

```bash
cd diwali_sales_analysis
```

### 3. Create a Virtual Environment (Recommended)

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

If the analysis is available only as an HTML export, open `Untitled319.html` in your web browser to view it. To rerun the analysis, include the original Jupyter Notebook (`.ipynb`) and the required dataset in the repository.
